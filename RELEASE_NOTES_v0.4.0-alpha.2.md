# HeimEnergie Dashboard v0.4.0-alpha.2

Die Leistungskurve jeder Gerätekarte zeigt jetzt die letzten zwölf Stunden. Auf dem Smartphone liegen einzelne Schaltzyklen dadurch weiter auseinander. Der Recorder liefert das passende Zeitfenster. Die Auswahl für kWh und Kosten gilt weiterhin für Tag, Woche, Monat oder Jahr.

In HACS/Marketplace die Vorabversion herunterladen und das Dashboard neu laden. Kompatibel mit HeimEnergie Integration v0.2.5.
